====================================================================
  wolphun emulator  0.3.0 (beta)  -  Maned Software
  Emulador de jogos mobile Mophun (PIP2), por Jamisson Tavares.
  -- pacote Debian/Ubuntu --
====================================================================

INSTALAR
  sudo apt install ./wolphun-emulator_0.3.0~beta-1_all.deb
  (o apt puxa o Java sozinho se faltar)

RODAR
  wolphun                       no terminal
  ou pelo menu de aplicativos   ("wolphun emulator", categoria Jogos)
  ou passando a ROM direto:     wolphun /caminho/jogo.mpn

DESINSTALAR
  sudo apt remove wolphun-emulator

REQUISITO
  Um Java 8 ou mais novo COM interface grafica (Swing):
      sudo apt install default-jre
  Nao serve o "-headless".

PRIMEIRA VEZ
  Menu  Arquivo > Definir pasta de ROMs...  e aponte para a pasta com seus
  jogos (uma subpasta por jogo, com o .mpn dentro). ROMs criptografados
  (.mpn com DRM) sao detectados e descriptografados automaticamente.

ONDE FICAM SEUS DADOS
  ~/.mophunemu/
    +- config.properties     configuracoes (video, som, controles, idioma)
    +- saves/<jogo>/         save NATIVO do jogo + save state (F5/F8)
    +- decrypted/            copias descriptografadas em cache dos .mpn

CONTROLES  (padrao; remapeaveis em Configuracoes > Controles)
  Mover ............. setas / WASD / numpad
  Fire / OK ......... Espaco, Enter, Ctrl
  Select (menu) ..... Q, tecla 0
  Fire2 ............. E, Backspace
  Voltar/sair ....... Esc        Limpar (tecla C) ..... Delete
  Save state: F5     Load state: F8
  Pausar: Ctrl+P     Maximizar: F11     Fechar: Ctrl+W

ARQUIVOS INSTALADOS
  /usr/bin/wolphun                        lancador
  /usr/lib/wolphun/wolphun.jar            o emulador
  /usr/share/applications/wolphun.desktop atalho do menu
  /usr/share/pixmaps/wolphun.png          icone
